# Πολιτική Απορρήτου — UniLoud Click-to-Call

Ημερομηνία ισχύος: 28 Ιουλίου 2026

Το UniLoud Click-to-Call επιτρέπει στον χρήστη να ξεκινά τηλεφωνικές κλήσεις
μέσω FreePBX ή Asterisk server που επιλέγει και λειτουργεί ο οργανισμός του.

## Αρχιτεκτονική

Δεν υπάρχει UniLoud cloud relay. Τα requests αποστέλλονται απευθείας, μέσω
HTTPS, στο PBX URL που έχει οριστεί. Αν η UniLoud λειτουργεί ξεχωριστά managed
PBX για πελάτη, ισχύουν οι αντίστοιχοι συμβατικοί όροι.

## Δεδομένα

Το extension επεξεργάζεται:

- HTTPS URL του PBX,
- API ID και API secret,
- επιλογή SIP/PJSIP και εσωτερικό,
- αριθμό προορισμού όταν ο χρήστης ζητά κλήση,
- προαιρετικό καθαρισμένο page URL.

Η αναγνώριση τηλεφωνικών αριθμών σε σελίδες είναι προαιρετική. Η σελίδα
αναλύεται τοπικά ώστε οι αριθμοί να γίνονται clickable. Δεν ανεβαίνει μαζικά το
περιεχόμενο της σελίδας. Ο επιλεγμένος αριθμός αποστέλλεται μόνο όταν ο χρήστης
ξεκινά κλήση.

Από το προαιρετικό page URL αφαιρούνται URL credentials, query string και
fragment πριν από την αποστολή.

## Τοπική αποθήκευση

Οι ρυθμίσεις αποθηκεύονται στο Chrome extension storage. Το API secret
παραμένει από προεπιλογή μόνο για τη συνεδρία. Αποθηκεύεται μόνιμα μόνο αν ο
χρήστης το επιλέξει ρητά. Ο χρήστης μπορεί να διαγράψει όλες τις ρυθμίσεις από
το popup ή αφαιρώντας το extension.

## PBX και logs

Το PBX μπορεί να καταγράφει request ID, IP, API client, εσωτερικό, protocol,
προορισμό, έκδοση extension και αποτέλεσμα για ασφάλεια και troubleshooting.
Το page URL δεν καταγράφεται από το παρεχόμενο backend εκτός αν ο PBX
administrator ενεργοποιήσει ρητά αυτή την επιλογή.

Ο operator του PBX ορίζει retention, πρόσβαση και διαγραφή των server-side
logs.

## Κοινοποίηση και εμπορική χρήση

Το extension δεν πουλά δεδομένα, δεν εμφανίζει διαφημίσεις, δεν εκτελεί
analytics και δεν χρησιμοποιεί δεδομένα για άσχετους σκοπούς. Τα στοιχεία
κλήσης δεν μεταφέρονται στην UniLoud ή σε τρίτους· αποστέλλονται μόνο στο PBX
που επέλεξε ο χρήστης για την εκτέλεση της κλήσης.

## Ασφάλεια

Απαιτείται HTTPS, η πρόσβαση σε σελίδες είναι προαιρετική και δεν γίνεται
download ή εκτέλεση remote code. Ο PBX operator είναι υπεύθυνος για TLS,
firewall, ενημερώσεις, rotation credentials και εξουσιοδότηση εσωτερικών.
