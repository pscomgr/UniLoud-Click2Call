# Chrome Web Store listing — English

## Product name

UniLoud Click-to-Call

## Summary

Call phone numbers from Chrome through your own FreePBX or Asterisk server using
SIP or PJSIP.

## Detailed description

UniLoud Click-to-Call connects Chrome directly to your organization’s
self-hosted FreePBX or Asterisk server.

Make calls in three ways:

- enter a number in Quick call;
- select a number on a page and use the right-click menu;
- optionally enable clickable phone-number detection on web pages.

Your administrator installs the included PHP 8.x backend on the PBX and gives
you a personal API ID and secret. The PBX rings your configured extension first
and then connects the destination.

Features:

- PJSIP and SIP / chan_sip;
- PJSIP multi-device ringing;
- explicit per-user extension allow-list;
- HTTPS-only PBX connection;
- English and Greek interface;
- session-only API secret by default;
- optional page access;
- optional sanitized page URL context.

Privacy by design:

- no advertising or analytics;
- no UniLoud cloud relay;
- no sale or sharing of call data;
- page phone detection is disabled until the user grants permission;
- query strings, URL credentials and fragments are never sent as page context.

Requires a compatible self-hosted backend. Ask your PBX administrator for the
HTTPS URL and personal credentials.
