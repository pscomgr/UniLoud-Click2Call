Privacy Policy — UniLoud Click-to-Call

Effective 28 July 2026

The extension sends call requests directly to the organization’s configured FreePBX/Asterisk server. There is no UniLoud cloud relay.

Data processed

The extension processes the PBX HTTPS URL, API identifier and secret, SIP/PJSIP choice, selected extension and the destination number when the user requests a call. A sanitized page URL is processed only if the user enables that option.

Automatic phone detection is optional. Page text is examined locally to make phone-like text clickable. Page content is not uploaded as a bulk dataset. A selected number is sent only when the user initiates a call. URL credentials, query strings and fragments are removed from optional page context.

Local storage

Connection settings use Chrome extension storage. The API secret is session-only by default and is stored persistently only when the user selects the remember-secret option. Users can clear settings from the popup or remove the extension.

PBX processing and retention

The selected PBX may process request ID, client IP, API client, extension, protocol, destination, extension version and result for security and troubleshooting. Page URLs are not logged by the supplied backend unless the PBX administrator explicitly enables that setting. The PBX operator controls server-side access, retention and deletion.

Sharing and use

The extension does not sell data, serve advertising, perform analytics or use data for creditworthiness or unrelated purposes. It does not transfer call data to UniLoud or third parties. Data is sent only to the PBX selected by the user to perform the requested call. If UniLoud separately operates a managed PBX, the applicable customer agreement governs that service.

Security

The extension requires HTTPS for PBX endpoints, makes page access optional and does not download or execute remote code. PBX operators are responsible for certificates, firewall policy, software updates, credential rotation and extension authorization.

Contact and changes

The product is intended for organizational telephony and is not directed to children. Material policy changes will update this page and its effective date. Use the private security or support channel in the official UniLoud Click-to-Call GitHub repository; never post secrets or call data in a public issue.

Σύνοψη: Τα requests αποστέλλονται μόνο στο PBX που ορίζει ο χρήστης. Δεν υπάρχει UniLoud cloud relay, analytics ή διαφημίσεις. Η πρόσβαση σε σελίδες και το page URL context είναι προαιρετικά.
